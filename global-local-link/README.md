# Global Local Link

A platform to connect expats with trusted English-speaking service providers worldwide.

## Project Overview

Global Local Link helps expats find verified English-speaking professionals for legal, childcare, healthcare, and relocation services in 50+ cities worldwide.

## Technologies Used

This project is built with:

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS
- React Router DOM

## Getting Started

### Prerequisites

- Node.js & npm installed - [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating)

### Installation

```sh
# Step 1: Clone the repository
git clone <YOUR_GIT_URL>

# Step 2: Navigate to the project directory
cd global-local-link

# Step 3: Install the necessary dependencies
npm install

# Step 4: Start the development server
npm run dev
```

## Available Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run preview` - Preview production build
- `npm run lint` - Run ESLint

## Development

The project uses:
- **Vite** for fast development and building
- **TypeScript** for type safety
- **React** with modern hooks
- **Tailwind CSS** for styling
- **shadcn/ui** for UI components

## Deployment

Build the project for production:

```sh
npm run build
```

The built files will be in the `dist` directory, ready for deployment to any static hosting service.
